# 💣 القنبلة

لعبة مسابقة جماعية لنادي نبراس. مجموعات تتنافس في وقت واحد، كل مجموعة معها عدّاد تنازلي
(قنبلة). الإجابة الصحيحة تضيف وقتاً والخاطئة تخصم، وأول قنبلة تنفجر تُنهي الجولة على الجميع.

## متجر البطاقات

بين الجولات تشتري المجموعات بطاقات بنقاطها — كل بطاقة **مرة واحدة** طوال اللعبة،
وتُطبَّق في الجولة التالية:

| البطاقة | الأثر | السعر |
|---|---|---|
| ⏱️ وقت إضافي | تبدأ الجولة القادمة بـ +5 ثوانٍ | 2 |
| ❄️ تجميد | تقفل مجموعة تختارها عن الإجابة 5 ثوانٍ في بداية الجولة (وعدّادها ينزل) — ويظهر لها اسم من جمّدها | 3 |
| ✕3 مضاعفة | نقاط جولتك القادمة ×3 — مجازفة: تضيع لو انفجرت | 4 |

## التشغيل محلياً

```bash
npm install          # اعتماديات السيرفر
npm run build        # بناء الواجهة
npm start            # http://localhost:3000
```

للتطوير مع إعادة التحميل التلقائي (نافذتان):

```bash
npm run dev          # السيرفر على 3000
npm run dev:client   # الواجهة على 5173 (تمرّر الطلبات إلى 3000)
```

## الاختبار

```bash
npm start            # في نافذة
npm test             # في أخرى — اختبار البطاقات ثم 52 فحصاً عبر سوكِت حقيقي
```

## الصفحات

| الصفحة | الرابط | لمن |
|---|---|---|
| التعريف | `/` | الجميع |
| المجموعة | `/play` | جهاز واحد لكل مجموعة |
| العرض | `/display` | البروجكتر |
| المسؤول | `/admin` | المنظّم |

## البنية

```
server/          سيرفر Node + Socket.IO — المرجع الوحيد للوقت والنتائج
  game.js        منطق اللعبة: الغرف، العدادات، النقاط
  banks/*.json   بنوك الأسئلة
client/          واجهة React + Vite + Tailwind
```

**قرارات تصميمية مهمة:**

- **الوقت يُحسب في السيرفر فقط** (نبضة كل 250 مللي‑ثانية). المتصفح يعرض ويُنعّم الحركة
  محلياً لكنه لا يقرر شيئاً — يمنع الغش ويوحّد كل الشاشات.
- **الإجابة الصحيحة لا تغادر السيرفر** قبل انتهاء الجولة، حتى لا تُقرأ من أدوات المطور.
- **لا قاعدة بيانات** — حالة الغرف في الذاكرة، وتُحذف الغرف الخاملة بعد ساعتين.

## النشر

> [!IMPORTANT]
> **شغّل نسخة واحدة فقط** (بلا autoscaling أو replicas). حالة اللعبة في ذاكرة العملية،
> فلو عملت نسختان قد ينضم فريق لواحدة وفريق لأخرى ولا يرى أحدهما الآخر.

المنصة يجب أن تدعم **الخوادم الدائمة و WebSocket** — لذلك لا تصلح المنصات الـ serverless
(Vercel / Netlify) لأن الحالة في الذاكرة و`setInterval` والاتصال الدائم لا تعيش فيها.

`railway.json` جاهز: البناء `npm run build`، التشغيل `npm start`، وفحص الصحة `/api/health`.
السيرفر يقرأ المنفذ من متغيّر البيئة `PORT` تلقائياً.

## إضافة بنك أسئلة

أنشئ ملفاً في `server/banks/` بهذا الشكل، وسيظهر تلقائياً في لوحة المسؤول:

```json
{
  "id": "sports",
  "name": "رياضة",
  "questions": [
    { "q": "كم عدد لاعبي فريق كرة القدم؟", "options": ["9", "10", "11", "12"], "answer": 2 }
  ]
}
```

`answer` رقم الخيار الصحيح بدءاً من الصفر.
